# Music Player

![Schematic](https://cdn.hackclub.com/01a0367d-280c-7633-958c-1bfefa1a6cfa/Screenshot%202026-08-24%20at%2018.16.01.png)

I built a music player that's powered by a seeed studio xiao rp2350 devboard and a dfplayer mini.
My initial goal was to just build something, like literally anything, for Kai's speedrun huddle and i realized it would be cool to have a music player that i could take places without bringing my phone. I learnt alot about PCB design and i used this cool plugin called (KiCad Routing tools)[https://github.com/drandyhaas/KiCadRoutingTools] it sped up routing a lot because i just had to layout the parts and didnt have to painstakingly look through where each one goes.
